# YMB ZOOM

Windows標準の拡大鏡(Magnifier)代替。指定した矩形領域を拡大表示し、見やすさのためのフィルタも複数かけられる
軽量な画面拡大アプリ。C# + WPF製、Magnification API(magnification.dll)を利用したDWM合成による低遅延ズーム。

## 主な機能

- **矩形指定3モード**:
  - ホットキー選択: 全画面オーバーレイでドラッグして矩形を1回選択
  - 常駐ドラッグ枠: 常に表示される枠をドラッグ移動・端でリサイズし、動かすたびリアルタイム反映
  - カーソル追従: 固定サイズの矩形がマウスカーソルに追従
- **ズーム操作**: ツールバーのスライダーのほか、ズーム画面上でのマウスホイールでも倍率変更可能
- **フィルタ(複数併用可)**: コントラスト/明度調整・反転・グレースケール・ハイコントラストモード・
  色弱対応(1型/2型/3型近似補正)・シャープ化(輪郭強調)。
  シャープ化のみMagnification APIのカラー行列で表現できないため、有効時だけソフトウェア描画経路
  (画面キャプチャ+畳み込みフィルタ)に自動切り替え。
- **トレイ常駐 / グローバルホットキーでのON-OFF切替 / 自動起動 / 二重起動防止**
- **設定の永続化**: ホットキー・既定の矩形指定モード・既定倍率・フィルタの状態を次回起動時に復元
- **本体の更新確認**: GitHub上の `version.json` と現在バージョンを比較し、起動時に自動チェック+
  設定画面から手動チェックも可能

## 使い方

- ツールバーの「矩形指定」でモードを選択。ホットキー選択は「矩形を選択...」ボタンから実行。
- 「倍率」スライダー、またはズーム表示領域上でのマウスホイールで拡大率を変更。
- グレースケール/反転/ハイコントラスト/色弱対応/コントラスト/明度/シャープ化は自由に組み合わせ可能。
- タイトルバーをドラッグしてウィンドウ移動、右下グリップでリサイズ。
- ×ボタンは既定でタスクトレイに常駐(非表示)。完全終了はトレイメニューの「終了」から。
- トレイアイコンの右クリックメニューから「設定...」でホットキーや既定値を変更可能。

## 技術スタック

- **言語/フレームワーク**: C# / .NET 8 (`net8.0-windows`) + WPF
- **ズーム描画**: Magnification API(`magnification.dll`)をP/Invokeし、ネイティブ"Magnifier"コントロールを
  `HwndHost`でWPFにホスト。DWM合成のため低遅延・低CPU。カラー行列(`MagSetColorEffect`)でコントラスト/
  反転/グレースケール/色弱対応フィルタを実現。
- **ソフトウェア描画経路**: シャープ化フィルタ有効時のみ、GDI `BitBlt`(`Graphics.CopyFromScreen`)で
  キャプチャした画像にアンシャープマスク畳み込みを適用し`WriteableBitmap`へ描画。
- **矩形指定UI**: オーバーレイ選択(`RectSelectOverlay`)、常駐ドラッグ枠(`WindowChrome`によるリサイズ/移動)、
  カーソル追従(`DispatcherTimer`)の3モードを`IZoomSource`インターフェースで統一。
- **常駐/ホットキー**: `NotifyIcon`によるトレイ常駐、`RegisterHotKey`によるグローバルホットキー、
  `Mutex`による二重起動防止。
- **設定/データ永続化**: JSON(`settings.json`)、`%APPDATA%\YmbZoom\`配下に保存(DB不使用)。
- **テスト**: xUnit(`YmbZoom.Tests`)。カラー行列合成・畳み込みフィルタの単体テスト。
- **インストーラー**: Inno Setup(`installer/setup.iss`)、日本語UI対応。
- **CI/CD**: GitHub Actions(`.github/workflows/release.yml`)、masterへのpushで
  テスト→バージョン自動繰り上げ→publish→インストーラービルド→GitHub Release公開まで自動化。

データ保存先: `%APPDATA%\YmbZoom\settings.json`

## 既知の制限

- **DRM保護された動画(Netflix等)はズーム画面に映らない(黒くなる)**。Windows標準の拡大鏡は
  `magnify.exe`固有の許可により保護コンテンツも表示できるが、この特別扱いはOSレベルで
  Microsoft純正プロセスに限定されており、サードパーティアプリには開放されていない。
  `uiAccess="true"` + コード署名 + Program Filesへのインストールという構成で検証したが、
  この組み合わせでも保護コンテンツは表示されなかった(2026-07時点)。DRM以外の通常の動画・
  画面内容は問題なくズームできる。

## ダウンロード

ビルド不要で使う場合は [Releases](https://github.com/yumebi/ymb_zoom/releases/latest) から
`YmbZoom-Setup-<version>.exe` をダウンロードして実行するだけでインストールできる
(self-contained、.NETランタイム別途インストール不要)。

> **注意**: このインストーラーはコード署名されていません。ダウンロード・実行時に
> Windows SmartScreenが「不明な発行元」として警告を表示する場合があります。
> 「詳細情報」→「実行」で続行できます。
